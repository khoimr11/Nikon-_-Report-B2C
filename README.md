# Bản đồ đối thủ máy ảnh — Nikon Việt Nam (Sales B2C · VHG)

Báo cáo nghiên cứu đối thủ (Canon, Sony, Fujifilm, DJI) trên Shopee, Lazada, website hãng, đại lý và TikTok, chốt số liệu 05/11/2026. Phục vụ yêu cầu của Sales B2C: (1) thông tin đối thủ trên sàn, website, social; (2) giá, khuyến mãi, cách bán; (3) cách đối thủ triển khai D2C / EC / B2C.

- Mở `index.html` hoặc bật GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/`).
- Ảnh trong `img/` là ảnh chụp màn hình trang của các thương hiệu/nhà bán, dùng nội bộ cho nghiên cứu.
- Logo Nikon thuộc Nikon Corporation.
